## Аннотация

Передача фрагментов исходного кода в запросах к большим языковым моделям стала одним из основных каналов утечки информации ограниченного доступа, тогда как детерминированные отпечатки (winnowing), применяемые в системах предотвращения утечек, разрушаются уже при переименовании идентификаторов, частичном извлечении или вставке мёртвого кода. В работе задача формулируется как проверка членства: принадлежит ли фрагмент q из запроса защищённой кодовой базе P с точностью до класса преобразований T. Предложен семантический слой LLM-файрвола — детектор D на основе контрастивно дообученного энкодера кода и поиска ближайших соседей в индексе эмбеддингов — и гибридный детектор, переранжирующий кандидатов семантического поиска отпечатками winnowing. Порог τ назначается конформной калибровкой по негативам, что даёт конечновыборочную границу уровня ложных срабатываний α без предположений о распределении скоров. Экспериментальный стенд моделирует защищённую базу репозиториями одной предметной области (сетевая безопасность, криптография), трудные негативы — другими репозиториями той же области, публичный корпус — репозиториями иных областей; запросы формируются программными преобразованиями (переформатирование, переименование, замена литералов, вставка мёртвого кода, перестановка операторов, частичное извлечение) и преобразованиями большой языковой модели (перефраз, перевод на другой язык программирования). Измеряются полнота при фиксированном уровне ложных срабатываний по классам преобразований, языкам и длинам фрагментов; соблюдение заявленной границы FPR при сдвиге распределения; латентность и память индекса для 10^5–10^6 функций; утечка из индекса эмбеддингов при атаках инверсии и выравнивания и влияние защит — ключевой ортогональной проекции Q, квантования и шума — на полноту членства. Ожидаемые вклады: формализация задачи семантического членства кода для LLM-файрвола, воспроизводимый стенд с открытым кодом, гибридный детектор с конформной гарантией FPR и эмпирическая оценка компромисса между приватностью индекса и полнотой обнаружения.

**Ключевые слова:** защита информации; большие языковые модели; утечка исходного кода; LLM-файрвол; отпечатки кода (winnowing); эмбеддинги кода; обнаружение клонов кода; конформная калибровка; атака инверсии эмбеддингов; защищённая кодовая база.

## Title, Abstract and Keywords

**Title:** Semantic Code Membership: Detecting Fragments of a Protected Codebase in Prompts to Large Language Models

**Authors:** [Authors, affiliation]

**Abstract.** Source code pasted into prompts to large language models has become a major channel for leaking restricted information, while the deterministic fingerprints (winnowing) used by data-loss-prevention systems break down once identifiers are renamed, a fragment is extracted partially, or dead code is inserted. We cast the problem as a membership test: does a fragment q from a prompt belong to a protected codebase P up to a class of transformations T? We propose a semantic layer for an LLM firewall — a detector D built on a contrastively fine-tuned code encoder with nearest-neighbour search over an embedding index — and a hybrid detector that reranks semantic candidates with winnowing fingerprints. The threshold τ is set by conformal calibration on negatives, giving a finite-sample bound on the false-positive rate α without distributional assumptions. The testbed models the protected codebase with repositories from one domain (network security, cryptography), hard negatives with other repositories from the same domain, and the public corpus with unrelated domains; queries are produced by programmatic transformations (reformatting, renaming, literal replacement, dead-code insertion, statement reordering, partial extraction) and by LLM paraphrase and cross-language translation. We measure recall at a fixed false-positive rate across transformation classes, languages and fragment lengths; adherence to the declared FPR bound under distribution shift; latency and index memory for 10^5–10^6 functions; and leakage from the embedding index under inversion and alignment attacks, together with the effect of defences (keyed orthogonal projection Q, quantization, noise) on membership recall. Expected contributions: a formalization of semantic code membership for LLM firewalls, a reproducible open-source testbed, a hybrid detector with a conformal FPR guarantee, and an empirical assessment of the index privacy–recall trade-off.

**Keywords:** information security; large language models; source code leakage; LLM firewall; code fingerprinting (winnowing); code embeddings; code clone detection; conformal calibration; embedding inversion attack; protected codebase.
