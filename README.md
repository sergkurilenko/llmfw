# llmfw — LLM Firewall: исследования и прототипы

Репозиторий исследовательского проекта по LLM-файрволу (защита взаимодействий с большими
языковыми моделями) с акцентом на предотвращение утечек конфиденциального исходного кода
в запросах к LLM.

## Структура

| Каталог | Содержимое |
|---|---|
| `docs/dissertation/` | Концепция диссертации, планы по LLM FW, бенчмарку и модулю защиты кода |
| `docs/semantic_membership/DESIGN.md` | Дизайн исследования слоя «семантическое членство кода» (источник истины для кода и статьи) |
| `experiments/semantic_membership/` | Экспериментальный стенд `smcode`: данные, преобразования, отпечатки, семантический энкодер (GPU), калибровка, атаки на индекс, оценка |
| `paper/` | Рукопись статьи «Семантическое членство кода…» (RU) и рисунки |

## Быстрый старт стенда

См. `experiments/semantic_membership/README.md` (runbook): CPU-части проверяются smoke-тестом
без GPU, обучение энкодера и LLM-преобразования выполняются на машине с GPU.

```bash
cd experiments/semantic_membership
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt          # CPU
pip install -r requirements-gpu.txt      # GPU-машина
bash scripts/smoke_test.sh               # сквозная проверка на синтетических данных
```

## Лицензии и данные

Корпуса кода, индексы и эмбеддинги не хранятся в репозитории (`.gitignore`). Списки
репозиториев — в `experiments/semantic_membership/configs/repos.yaml`; перед публикацией
результатов проверяются лицензии источников.
